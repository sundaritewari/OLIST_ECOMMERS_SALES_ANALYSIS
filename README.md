# 📊 Olist E-Commerce Sales Analysis

An end-to-end **E-Commerce Sales Analysis project** built using Microsoft Excel to analyze sales performance, customer behavior, order trends, and delivery performance using the **Brazilian Olist E-Commerce dataset**.

## 🎯 Project Objective

The objective of this project is to transform raw e-commerce data into meaningful business insights through **data cleaning, data transformation, Pivot Tables, KPIs, interactive slicers, and dashboard visualization**.

## 🛠️ Tools & Techniques

* Microsoft Excel
* Power Query
* Pivot Tables
* Pivot Charts
* Slicers
* Timeline
* Data Cleaning & Transformation
* KPI Analysis
* Dashboard Design

## 📌 Key KPIs

* Total Sales
* Total Orders
* Total Customers
* Average Order Value
* Delivery Rate
* Average Delivery Days

## 📈 Dashboard Analysis

The dashboard provides insights into:

* Monthly Sales Trends
* Sales by Product
* Sales by Customer State
* Top Customers by City
* Order Status Analysis
* Delivery Performance
* Overall E-Commerce Performance

💡 Key Business Insights

The analysis helps identify sales trends, customer distribution, high-performing products and locations, order-status patterns, and delivery performance.

These insights can support better **sales planning, customer analysis, operational monitoring, and delivery performance improvement**.
